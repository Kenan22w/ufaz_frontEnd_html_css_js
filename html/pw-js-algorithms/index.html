PW JS Algorithmics — Homepage

Three exercises written in HTML and JavaScript. The JavaScript algorithms print their results in the browser console.

How to check: Open one exercise, press F12, select Console, and reload the page.

  • 1. Equality
    Find three-digit numbers equal to the sum of the cubes of their digits.
  • 2. Give change back
    Compute the number of banknotes for an amount in Azerbaijani manat.
  • 3. Luhn algorithm
    Calculate and verify a fictional card-number check digit.

Each exercise opens in its own HTML page, as required by the practical-work instructions.
